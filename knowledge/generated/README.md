# knowledge/generated

Este directorio está reservado para conocimiento generado automáticamente en
fases futuras (por ejemplo, resúmenes de patrones detectados con alta
frecuencia, antes de convertirse en propuestas formales). En esta v1 está
vacío a propósito: todo el conocimiento vive en SQLite (`observations`,
`knowledge`) hasta que sea validado, y en `knowledge/business/*.md` para la
documentación funcional editada por humanos.
